# E-commerce Sales Analysis

## Project Overview

This project analyzes e-commerce transaction data to understand sales performance, customer behavior, product demand, and revenue trends.

## Objectives

- Clean and prepare sales data.
- Analyze revenue and customer transactions.
- Identify top-selling products and countries.
- Analyze monthly sales trends.
- Create an interactive Power BI dashboard.
- Provide business recommendations based on the results.

## Tools and Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL (SQLite)
- Power BI
- Google Colab

## Dataset

UCI Online Retail Dataset

Source: https://archive.ics.uci.edu/dataset/352/online-retail

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. SQL Analysis
5. Data Visualization
6. Power BI Dashboard
7. Business Insights

## Key Findings

- **Total Revenue:** £8,885,586.15
- **Total Orders:** 17,282
- **Average Order Value:** £514.15
- **Highest Revenue Country:** United Kingdom (£7.28M, approximately 82% of total revenue)
- **Highest Revenue Product:** PAPER CRAFT, LITTLE BIRDIE (£168,469.60)
- **Highest Spending Customer:** Customer ID 14646 (£280,206.02)

### Business Recommendations

- Explore opportunities to increase sales outside the United Kingdom.
- Monitor inventory for high-revenue products.
- Consider loyalty programs for high-value customers.
- Analyze seasonal revenue trends to improve inventory planning.

## Conclusion

This project demonstrates how Python, SQL, and Power BI can be combined to analyze business performance and support data-driven decisions.
